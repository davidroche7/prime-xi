# PRIME XI

Build your club's greatest XI — every player at their peak. Static, serverless,
accountless. See `PRD.md` for the product and `CLAUDE.md` for the operating spec.

## Stack

Next.js (App Router, `output: 'export'`) · TypeScript · Tailwind v4 · pnpm · Vitest.
Hosted on **Cloudflare Pages** (static output in `out/`). Analytics via Plausible
(enabled only when `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` is set).

## Commands

```bash
pnpm install
pnpm dev              # local dev server
pnpm test             # unit tests (scoring/cost/prng/dailyPuzzle) + /data validation
pnpm typecheck        # tsc --noEmit
pnpm build            # static export → out/
pnpm pipeline:export  # regenerate /data from pipeline seeds (offline only)
pnpm pipeline:tune    # §5.2 budget tuning report (fails if out of target)
```

## Deploy (Cloudflare Pages)

- Build command: `pnpm build`
- Output directory: `out`
- Env (optional): `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_PLAUSIBLE_DOMAIN`,
  `NEXT_PUBLIC_ADS_ENABLED` (ships off).

## Layout

- `/data` — static JSON (clubs, formations, index), generated by `/pipeline`, committed.
- `/pipeline` — offline only, never deployed: curated seeds → costs/budgets → JSON.
- `/src/lib` — pure, deterministic, unit-tested: `scoring`, `cost`, `prng`, `dailyPuzzle`.
- `/src/app` — home, `/club/[slug]` (builder + SEO prose + FAQ JSON-LD), `/daily`, sitemap.
- `/src/components` — Pitch, PlayerPicker, BudgetBar, ScorePanel, TierBadge, ShareCard (canvas), AdSlot.

## Data & legal

No club badges, kits, crests, or competition marks — club names and historical stats
only, with generic colour themes. Ratings are editorial estimates computed offline;
production never scrapes or computes them at runtime.
